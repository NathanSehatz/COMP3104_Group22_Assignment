## Project Description
This repository contains the COMP3104 DevOps Group Assignment for Group 22.

The purpose of this project is to demonstrate the use of Git version control, GitHub collaboration, branching strategies, pull requests, and CI/CD using GitHub Actions.

Each team member will work on their own branch, contribute files, and collaborate to merge their work into the main branch.

## Branching Strategy
Each member works on an individual branch using the following naming convention:

STUDENTID-Name

All changes will be reviewed and merged into the main branch through pull requests.

## CI/CD Pipeline
GitHub Actions will be used for continuous integration.

The workflow will be located at:

.github/workflows/ci.yml

The workflow will automatically run when changes are pushed or pull requests are created.

## Project Files
Each team member will contribute three text files:

- STUDENTID_gb.txt - Information about George Brown College.
- STUDENTID_devops.txt - Information about the DevOps course.
- STUDENTID_sdlc.txt - Importance of DevOps in the Software Development Life Cycle.

## Setup Instructions
1. Clone the repository.
2. Create a personal branch using the STUDENTID-Name format.
3. Create the three required text files.
4. Make at least 10 meaningful commits.
5. Push changes to GitHub.
6. Create a pull request to merge changes into main.
