
COMP3104 - Developer Operations

COMP3104 introduces students to DevOps principles, tools, and practices used in modern software development.

DevOps combines software development (Dev) and IT operations (Ops) to improve collaboration, automate processes, and deliver software more efficiently.

One important topic in the course is version control using Git and GitHub. Git allows developers to track changes to their code, while GitHub provides a platform for sharing repositories and collaborating with other developers.

Students also learn about continuous integration and continuous delivery (CI/CD). These practices help automate software testing and integration, reducing errors and improving software quality.

GitHub Actions is an example of a CI/CD tool that can automatically execute workflows whenever developers push changes or create pull requests.

Git Branching and Collaboration

Git branching allows developers to work independently without immediately affecting the main version of a project.

Each developer can create their own branch, make changes, and commit their work. These changes can then be reviewed through a pull request before being merged into the main branch.

Pull requests help teams identify errors, discuss improvements, and maintain code quality.

Continuous Integration and Automation

Continuous Integration (CI) involves regularly integrating changes into a shared repository and automatically checking whether those changes work correctly.

GitHub Actions allows developers to configure automated workflows using YAML files stored in the .github/workflows directory.

These workflows can run on events such as pushes and pull requests, helping teams detect problems early in the development process.

Benefits of DevOps in Team Projects

DevOps is especially useful when multiple developers collaborate on the same project.

Version control systems such as Git allow team members to work independently while maintaining a shared history of changes. GitHub provides tools such as pull requests and code reviews to help teams collaborate effectively.

Automated workflows also reduce repetitive tasks and help ensure that new changes do not introduce problems.

For our COMP3104 Group 22 assignment, we use individual Git branches, descriptive commits, pull requests, and GitHub Actions to demonstrate these DevOps practices.

This approach improves collaboration, accountability, and software development efficiency.
