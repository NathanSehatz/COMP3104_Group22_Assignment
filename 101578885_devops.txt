COMP3104 DevOps

DevOps brings software development and IT operations together.
It emphasizes collaboration, automation, and continuous feedback
to improve how software is built, tested, and delivered.

This assignment provides practice with Git, GitHub, branching,
pull requests, and continuous integration.


Resolving Merge Conflicts

A merge conflict can occur when branches change the same lines.
The developer reviews both versions, keeps the intended content,
and removes the conflict markers.

After checking the result, the developer stages the resolved files
and commits the resolution. Regularly bringing main into personal
branches helps members identify conflicts before the final merge.
